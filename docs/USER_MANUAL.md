# User Manual

UI note: the frontend supports Romanian (default) + English, and light/dark themes via header toggles.

## Student
- Login with `Student Login (Mock Google OAuth)` using `@student.usv.ro`
- Browse events list and calendar
- View event details, export `.ics`, register/cancel registrations
- Leave feedback after event ends

## Organizer
- Login with username/password
- Create draft events and submit for approval
- Upload materials locally
- View participants/waiting list, check-in by ticket QR payload

## Administrator
- Login with username/password
- Manage organizers, approve/reject events
- Generate reports (JSON + local PDF)
- Run mock scraping and approve drafts into events
